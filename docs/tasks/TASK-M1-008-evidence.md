## Implementation Architecture

TASK-M1-008 adds `curios_runtime.executor_seam`.

The module provides:

- `ExecutorRequest`: one inert request over canonical `WorkItem`,
  `WorkDagNodeReadiness`, `CapabilityResolution`, optional selected
  `AgentInstance`, caller-supplied `EventId`/`EvidenceId`, canonical
  `ObjectReference` producer, and canonical `ObservabilityContext`;
- `ExecutorOutcome`: one inert outcome containing bounded status, canonical
  `Result`, canonical `EventEnvelope`, and any produced `EvidenceReference`;
- `M1Executor`: a fakeable protocol seam;
- `DeterministicM1Executor`: fixed deterministic executor behavior for the six
  work types generated by TASK-M1-003;
- `ExecutorOutcomeStatus` and `ExecutorErrorCode`: bounded local vocabularies.

The fixed supported work types are:

- `collect_recorded_context`;
- `compose_recorded_summary`;
- `verify_recorded_summary`;
- `inspect_current_state`;
- `apply_bounded_change`;
- `verify_bounded_change`.

`apply_bounded_change` records a deterministic no-side-effect outcome. It does
not mutate the repository or perform arbitrary tool execution.
